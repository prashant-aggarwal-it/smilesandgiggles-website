# Security Policy

## Reporting a vulnerability

Please report suspected security issues privately to **smilesandgigglesfoundation@gmail.com**.

Do not open a public GitHub issue for vulnerabilities that could expose user data, payment flows, form submissions, credentials, or deployment infrastructure.

Please include the affected page or component, reproduction steps, impact, and any relevant screenshots or logs. We will review the report and respond through the contact details provided.

## Scope

This repository contains the public website. Payment information is handled by Razorpay's hosted checkout and should never be committed to this repository. Secrets, API keys, private certificates, donor records, and form exports must not be stored in source control.
