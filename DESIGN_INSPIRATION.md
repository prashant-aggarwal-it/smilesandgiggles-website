# Design Inspiration Notes

This refinement uses public websites only as pattern references. It does not copy their brand identity, imagery, text or proprietary layouts.

## STEMmantra — useful patterns

Reference: https://www.stemmantra.com/

Useful ideas observed:
- establish proof/scale early near the top of the experience
- explain methodology visually instead of only through paragraphs
- create structured program pathways/cards
- show implementation as an understandable journey
- use clear school/institution partnership CTAs

How we adapted this:
- stronger `ImpactStatsSection`
- reusable `MakerLoop` using our existing Build / Test / Improve / Code / Create language
- stronger `ProgramCard` hierarchy
- more visible implementation-step nodes and connecting line

## Nirmaan STEM & Robotics Program — useful patterns

Reference: https://nirmaan.org/holistic-education/stem-labs-robotics-program

Useful ideas observed:
- visible impact block near program introduction
- concise visual "what we do" cards
- real-world project/gallery storytelling
- clear partner/contribute pathways
- use program evidence and field photography to build trust

How we adapted this:
- impact stat tiles now carry distinct brand colours
- focus/support/partner cards have clearer visual identities
- classroom gallery gets stronger colour coding while keeping authentic photography central
- CSR pathways have more distinctive cards and a clearer emerging-opportunities block

## Broader nonprofit / education UX principle

The website should combine institutional trust with human storytelling. Colour and motion help establish personality, but authentic field photography and clear evidence should remain dominant.
