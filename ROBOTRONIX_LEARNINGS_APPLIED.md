# Robotronix™ Production Learnings Applied to the Foundation Site

This revision was compared directly against `robotronix-website-v1.0.0-production-ready.zip`.

## Adapted because they fit a nonprofit/community website

- **Proof-led hero:** concise delivery-strength chips reinforce credibility without adding sales copy.
- **Compact discovery rail:** the Robotronix ecosystem strip inspired a calmer, non-commercial impact-area rail linking directly to STEM, AI/digital skills, preventive health, CSR and Get Involved.
- **Evidence-first photography:** reusable field-evidence labels help real classroom/community imagery carry more of the story.
- **Predictable route scrolling:** App Router navigation now resets cleanly or lands correctly on hash sections.
- **Production preflight:** internal-link, asset and production checks were added alongside the existing site audit.
- **Netlify-ready workflow:** production build command, Node 22 configuration and GitHub quality workflow are included.
- **Runtime resilience:** an application error page and web app manifest were added.
- **Security parity:** the stronger safe response headers used by the Robotronix production site were adopted.
- **SEO sharing:** the default Open Graph/Twitter image is now explicitly defined.

## Deliberately NOT copied

The Foundation is not a commercial Robotronix microsite. This revision therefore does **not** import:

- program finder / grade recommendation logic
- pricing, admissions or sales urgency
- parent testimonials or private-course conversion copy
- demo-booking mechanics
- Robotronix brand imagery, logos or private-business proof points
- commercial course/catalogue content
- WhatsApp-first enquiry architecture
- sales-focused announcement language

The Foundation retains its own mission, community-work framing, governance, donation, volunteer and CSR architecture.
